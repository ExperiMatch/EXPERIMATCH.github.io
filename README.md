💜 ExperiMatch – Recomendación de experiencias

ExperiMatch es una plataforma web diseñada para facilitar el descubrimiento de lugares y experiencias de entretenimiento, gastronomía y actividades sociales en Colombia.

Su objetivo es ayudar a las personas a encontrar planes de acuerdo con sus intereses, preferencias y ubicación, ofreciendo información organizada sobre diferentes lugares.

✨ Características principales

- 🔎 Búsqueda de lugares y experiencias.
- 🏷️ Filtros por categorías y preferencias.
- 👤 Registro e inicio de sesión de usuarios.
- ❤️ Guardado de lugares favoritos.
- ⭐ Reseñas y valoraciones.
- 📍 Información sobre lugares y ubicaciones.
- 👤 Perfil personal de usuario.

🛠️ Tecnologías utilizadas

- HTML5
- CSS3
- PHP
- JavaScript
- MySQL
- XAMPP

📁 Estructura del proyecto

- "index.php": Página principal.
- "index.html": Página HTML alternativa, si se utiliza.
- "login.php": Registro e inicio de sesión.
- "perfil.php": Perfil del usuario.
- "database.php": Conexión con la base de datos.
- "style.css": Estilos y diseño visual.

💻 Instalación local

1. Instalar XAMPP.
2. Iniciar Apache y MySQL.
3. Colocar la carpeta ExperiMatch dentro de "htdocs".
4. Crear la base de datos correspondiente en phpMyAdmin.
5. Configurar la conexión en "database.php".
6. Abrir el proyecto desde:

"http://localhost/ExperiMatch/"

🎯 Propósito

ExperiMatch busca mejorar la manera en que las personas descubren y seleccionan experiencias, reuniendo diferentes alternativas en un solo espacio digital y ofreciendo recomendaciones más acordes con sus intereses.
